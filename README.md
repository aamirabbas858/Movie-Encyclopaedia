# Movie Encyclopaedia

A vanilla JavaScript movie search app built to practice async/await and working with a third-party REST API.

## What it does

Search for any movie by title and get back the poster, release year, rating, and overview — pulled live from the TMDB API.

## Stack

HTML · CSS · Vanilla JavaScript · TMDB API

## Running locally

Clone the repo, add your TMDB API key to `script.js`, and open `index.html` in a browser.
